# 🌡️ 熱中症リスクモニター

現在地の位置情報をもとに、気温・湿度・WBGT（暑さ指数）・波浪情報をリアルタイムで表示する静的Webアプリです。  
スマートフォン・タブレット・PCのブラウザで動作します。アプリのインストール不要。

## 機能

- **WBGT（暑さ指数）のリアルタイム表示** — 環境省基準で5段階の危険度を色と文字で表示
- **時間帯別予報** — 今日の各時間帯のWBGT・気温・湿度を横スクロールで確認
- **波浪情報** — 最寄り港（全国133港から自動選択）の波高・うねり方向を表示
- **対策アドバイス** — 危険度レベルに応じたアドバイスを3件表示
- **熱中症チェックガイド** — 症状を選ぶだけで応急対処法をステップ案内（119/118への発信ボタン付き）
- **最寄り海上保安部の案内** — 全国72拠点から現在地に近い順に3拠点を表示・電話発信可能
- **地図から任意の場所を選択** — Leaflet.js（OpenStreetMap）の地図をタップ・クリックして任意の場所のデータを取得。🔄更新ボタンでGPS現在地に戻る

## 使用API・ライブラリ（すべて無料・APIキー不要）

| サービス | 用途 |
|---------|------|
| [Open-Meteo](https://open-meteo.com/) | 気温・湿度・風速・風向の取得 |
| [Open-Meteo Marine API](https://open-meteo.com/) | 波浪・うねり情報の取得 |
| [Nominatim (OpenStreetMap)](https://nominatim.org/) | 緯度経度→地名変換（逆ジオコーディング） |
| [Leaflet.js](https://leafletjs.com/) | 地図表示・任意の場所選択 |
| ブラウザ Geolocation API | 現在地の緯度経度取得 |

## WBGT計算について

気温・湿度から環境省方式に準拠した近似式でWBGTを算出しています。  
日射の影響は含まれないため、炎天下では実際の値より低めに出る場合があります。

## 危険度基準（環境省）

| WBGT | 危険度 |
|------|--------|
| 〜21°C | 安全 |
| 21〜25°C | 注意 |
| 25〜28°C | 警戒 |
| 28〜31°C | 厳重警戒 |
| 31°C〜 | 危険 |

## 波浪情報について

全国133の重要港湾・国際拠点港湾の座標をツール内に収録しています。現在地から最も近い港の座標をもとにOpen-Meteo Marine APIから波浪予報を取得します（約25km格子の予報値）。陸上でも最寄り港を基準に表示します。

## データ出典

| データ | 出典 |
|--------|------|
| 海上保安部の連絡先・電話番号・所在地座標 | 国土交通省 海上保安庁「海上保安部事務所一覧」（jimusyoitiran.pdf）をもとに作成 |
| 収録港湾リスト・座標 | 国土交通省「重要港湾・国際拠点港湾・国際戦略港湾」一覧をもとに作成 |
| WBGT危険度基準 | 環境省「熱中症予防情報サイト」の暑さ指数（WBGT）基準に準拠 |

## 注意事項

- 位置情報の使用許可が必要です（ブラウザのプロンプトで「許可」を選択）
- HTTPS環境でのみ位置情報が取得できます（GitHub PagesはHTTPSなのでOK）
- WBGTは近似値です。作業可否の最終判断は必ず現場責任者が行ってください
